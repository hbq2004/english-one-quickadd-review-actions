# 英语一 QuickAdd 复习操作

一个面向考研英语一复习流程的 [QuickAdd](https://github.com/chhoumann/quickadd) 用户脚本。它把学习记录、阅读复盘、作文二稿、长难句、Anki 问答卡和阶段回看集中到一个命令入口，并让 YAML、Tasks 与 Dataview 使用同一套数据。

本仓库只负责 QuickAdd 写入端；只读统计面板见 [english-one-dataview-review-dashboard](https://github.com/hbq2004/english-one-dataview-review-dashboard)。

## 功能概览

脚本提供一个包含六项操作的宏：

| 操作 | 主要结果 | 是否自动记录学习会话 |
|---|---|---:|
| 记录复习会话 | 新建一条 `english-session`，可向当日日记追加回链 | 是 |
| 创建阅读复盘 | 新建阅读复盘、1/3/7/21 天任务及关联会话 | 是 |
| 创建作文复盘 | 新建限时初稿、次日二稿任务及关联会话 | 是 |
| 抓取长难句 | 从选区或剪贴板生成拆句笔记 | 填写分钟数时才记录 |
| 制作 Anki 问答卡 | 向当日 Anki 文件追加一组 `Q:`/`A:` | 否 |
| 完成阶段复习 | 完成或顺延阅读阶段，或完成作文二稿 | 否 |

脚本有意保持以下边界：

- 不联网，不调用 AI，也不自动下载内容。
- 不自动创建当日日记；日记已存在时才追加回链。
- 不自动运行 Anki 扫描；生成卡片后仍需手动执行 `Obsidian_to_Anki: Scan Vault`。
- 不覆盖同名笔记；重名时使用 `-2`、`-3` 等后缀。
- 阅读、作文或长难句主笔记创建成功后，若关联会话创建失败，主笔记不会回滚，并会显示补记提示。
- 学习会话已经创建后，若当日日记回链写入失败，时长记录不会回滚；脚本会明确提示不要重复补记。
- 笔记或卡片已经保存后，若自动打开文件失败，已写入内容不会回滚；请从文件列表手动打开，不要重复执行写入操作。

## 前置要求

直接依赖：

- Obsidian；
- QuickAdd 2.20 或更高版本。

按需集成：

- Tasks：识别脚本生成的复习任务；
- PDF++：复制带回链的原文证据；
- Obsidian_to_Anki：扫描 `Q:`/`A:` 问答卡；
- Dataview：配合另一个仓库显示统计面板。

Templater 不是本脚本的运行依赖。Node.js 只用于运行仓库测试，不参与 Obsidian 内的日常使用。

## 默认目录

脚本顶部的 `PATHS` 默认对应以下库结构：

```text
03 - 英语/
├─ 02 - 真题复盘/
│  ├─ 复习记录/          # english-session
│  ├─ 阅读/              # english-reading
│  ├─ 长难句/            # english-sentence
│  └─ 作文/              # english-writing
└─ Anki/                 # 按天聚合的 Q/A 卡片

_Daily_Tasks/
└─ YYYY-MM-DD.md         # 可选；仅在已存在时写入会话回链
```

除当日日记外，生成目录会在第一次使用时逐层创建。如果某一级路径已经被同名文件占用，脚本会停止并提示错误。

若你的目录不同，请修改 `english-review-actions.js` 顶部的 `PATHS`。同时使用统计面板时，还必须同步修改 Dashboard 仓库 `view.js` 顶部的路径常量，否则脚本能创建数据，但面板读不到它们。

## 安装

### 1. 复制脚本

将 `english-review-actions.js` 放入库内：

```text
_Scripts/english-quickadd/english-review-actions.js
```

### 2. 创建 QuickAdd 宏

1. 打开 QuickAdd 设置，新建一个 **Macro** Choice。
2. 命名为 `英语一｜复习操作`。
3. 进入 Macro 管理界面，添加一个 **User Script** 动作。
4. 选择 `_Scripts/english-quickadd/english-review-actions.js`。
5. 打开该 Choice 的闪电图标，使它出现在 Obsidian 命令面板中。
6. 可选：给 `QuickAdd: 英语一｜复习操作` 绑定一个快捷键。

建议先运行一次“记录复习会话”，确认能在 `复习记录` 目录创建笔记，再开始录入阅读或作文。

## 六项操作详解

### 1. 记录复习会话

输入：

| 字段 | 规则 |
|---|---|
| 复习类型 | 词汇、语法、阅读、长难句、翻译、完形、新题型、小作文、大作文、套卷复盘或其他 |
| 有效学习分钟 | 必填，`1–600` |
| 数量 | 可空，`0–5000` |
| 材料来源 | 可空 |
| 结果 | 可空 |

输出一条唯一的 `english-session` 笔记。文件名包含本地日期、精确到秒的时间和训练类型；同秒重名时自动添加数字后缀。

数量留空时，YAML 仍写入 `amount: 0`，正文显示 `-`；明确输入 `0` 时，YAML 与正文都会保留 `0`。

如果 `_Daily_Tasks/YYYY-MM-DD.md` 已存在，脚本会把会话链接写入其 `## 英语记录` 章节，并添加唯一 HTML 标记防止同一会话被重复写入。章节后面即使还有其他二级标题，回链也会保留在英语记录章节中。脚本不会为了回链自动创建日记。

### 2. 创建阅读复盘

输入：

| 字段 | 规则 |
|---|---|
| 真题年份 | `1997–2026` |
| 篇目 | `Text-1` 至 `Text-4` |
| 首做正确题数 | `0–5`；允许 0 分 |
| 首做用时 | `1–90` 分钟 |
| 主错因 | 无、词义、句法、定位、逻辑、选项偷换、主旨、态度、时间或粗心 |
| 资料名称 | 可空 |
| PDF++ 原文证据 | 可空；写入前可以确认和编辑 |

脚本会：

1. 创建 `english-reading` 复盘笔记；
2. 固定写入 `total: 5`；
3. 安排第 1、3、7、21 天的 YAML 日期与 Tasks；
4. 自动创建一条 `kind: 阅读` 的关联会话；
5. 当日日记存在时写入会话回链；
6. 打开新建的阅读复盘。

选择“无”错因时生成 `error_tags: []`，其他选项生成单元素数组。阅读已经自动记时，不要再为同一篇阅读运行一次“记录复习会话”。

### 3. 创建作文复盘

输入作文类型（小作文或大作文）、题目关键词、`1–90` 分钟的限时初稿用时，以及可选的题目来源和任务点。

脚本会创建：

- `english-writing` 笔记；
- 次日 `rewrite_due`；
- 一条“完成自改二稿”的 Tasks；
- 一条类型为小作文或大作文的关联会话。

“完成阶段复习”可以完成作文二稿；作文二稿当前没有“禁止提前完成”的日期限制。

### 4. 抓取长难句

文本读取顺序为：

1. QuickAdd 当前编辑器选区；
2. 旧版 QuickAdd 兼容选区接口（仅在新版接口不存在时使用）；
3. 系统剪贴板；
4. 手工输入。

原句和语法标签必填。拆句分钟可空；填写时必须为 `1–120`，并会额外创建一条关联会话。

生成的 `english-sentence` 包含次日重译任务，但“完成阶段复习”当前只处理阅读和作文，不处理长难句任务。模板不会生成行首 `Q:` 或 `A:`，避免被 Obsidian_to_Anki 误扫为空卡。

### 5. 制作 Anki 问答卡

卡片类型、正面和背面均必填。多行输入会转换为 `<br>`，保证每张卡严格占用一行 `Q:` 和一行 `A:`：

```text
TARGET DECK: 英语

Q: address 作动词的高频义？
A: 处理、应对（问题）
```

卡片按本地日期聚合到：

```text
03 - 英语/Anki/YYYY-MM-DD.md
```

添加前会扫描 Anki 目录，按正面文字做“不区分大小写的精确匹配”。发现重复时只有明确选择继续才会添加；关闭确认框或选择取消属于正常取消，不显示失败 Notice。

新文件使用 `TARGET DECK: 英语`。已有文件若包含以大写 `TARGET DECK:` 开头的行，脚本会保留原值；这允许你手工覆盖牌组，但也意味着写入 `TARGET DECK: OTHER` 的当日文件时，新英语卡会进入该牌组。

脚本不会调用 AnkiConnect。添加后请打开 Anki，再运行：

```text
Obsidian_to_Anki: Scan Vault
```

### 6. 完成阶段复习

先打开一篇 `type: english-reading` 或 `type: english-writing` 的 Markdown 笔记，再运行该操作。

阅读会在已经配置的阶段中，按 `1 → 3 → 7 → 21` 查找第一个未完成阶段。某阶段的日期与 `_done` 字段都缺失时，视为未配置并跳过；如果没有任何已配置阶段，脚本会拒绝操作。

- 日期晚于今天：拒绝提前完成；
- 选择“通过”：设置 `review_N_done: true`，写入 `last_reviewed`，勾选对应任务并追加复习历史；
- 选择“不稳”：把当前阶段顺延到明天，保持 `review_N_done: false`，同步任务日期并追加复习历史。

脚本会从文件重新读取最新 YAML；文件开头带 UTF-8 BOM，或 YAML 分隔符 `---` 后带空格时也能识别。更新前会确认到期日期合法，并要求目标章节内恰好存在一条标签正确、`📅 YYYY-MM-DD` 与 YAML 日期一致的任务。任务缺失、重复、被改名、日期不一致或格式被破坏时，脚本会停止并保持 YAML 不变。

若 YAML 已写入但正文写入发生异常，脚本会尝试回滚 YAML；如果回滚本身也失败，会明确提示立即人工核对当前笔记。同一篇笔记的并发完成请求会串行执行，并在轮到执行时重新读取文件，避免旧缓存重复完成或覆盖较新的状态。

作文会设置 `rewrite_done: true`、写入 `last_reviewed` 并勾选二稿任务。作文二稿不限制提前完成，但 `rewrite_due` 必须是合法日期，且二稿任务的日期必须与它一致。已经手工勾选但仍保留原任务文字和日期的任务，也可以再运行本操作来同步 YAML。

## 数据契约

### `english-session`

| 字段 | 类型 | 说明 |
|---|---|---|
| `type` | string | 固定为 `english-session` |
| `date` | `YYYY-MM-DD` | 本地日期 |
| `time` | `HH:mm` | 本地时间 |
| `kind` | string | 训练类型 |
| `minutes` | number | 有效学习分钟 |
| `amount` | number | 数量；空输入写为 0 |
| `source` | string | 材料来源 |
| `result` | string | 训练结果 |
| `related` | string，可选 | 关联阅读、作文或长难句路径 |

只有 `english-session.minutes` 应计入有效学习时间。阅读和作文笔记虽然也含有 `minutes`，但它们已经自动创建关联会话，不能重复相加。

### `english-reading`

关键字段包括：

```yaml
type: english-reading
date: 2026-08-02
paper_year: 2018
passage: "Text-2"
section: "阅读A"
correct: 4
total: 5
minutes: 21
error_tags: ["定位"]
review_1: 2026-08-03
review_1_done: false
review_3: 2026-08-05
review_3_done: false
review_7: 2026-08-09
review_7_done: false
review_21: 2026-08-23
review_21_done: false
```

不要删除、重命名或改变这些字段的类型。布尔值应使用未加引号的 `true`/`false`。

### `english-writing`

关键字段为 `type`、`date`、`genre`、`topic`、`source`、`minutes`、`rewrite_due` 和 `rewrite_done`。

### `english-sentence`

关键字段为 `type`、`date`、`source`、`grammar_tags`、`review_1`、`review_1_done` 和 `anki_ready`。

## Tasks、PDF++ 与日记集成

- Tasks 同步依赖脚本生成的目标章节、任务标签、复选框和 `📅 YYYY-MM-DD` 日期。对应任务必须唯一，且日期必须与 YAML 一致。可以在任务末尾保留 Tasks 的完成日期，但不要让 Linter 改写标签或日期 emoji。
- 手工勾选 Tasks 本身不会改 YAML；请运行“完成阶段复习”完成最终同步。
- PDF++ 只是文本来源。脚本读取复制结果，不调用 PDF++ API，也不会修改 PDF。
- 日记回链使用 `<!-- english-session:路径 -->` 去重。日记不存在时会静默跳过；若日记存在但回链写入失败，会话和时长仍然有效，不要重复补记。

## 测试

测试不依赖 npm 包，只需要现代 Node.js。在仓库根目录运行：

```powershell
node english-review-actions.test.js
```

测试文件也支持用环境变量指向另一份脚本：

```powershell
$env:QUICKADD_SCRIPT = "D:\path\to\english-review-actions.js"
node english-review-actions.test.js
```

当前测试覆盖 24 个场景，包括：阅读、作文、长难句与 Anki 正常流程；取消语义；阅读通过、顺延、未来日期与非法日期；旧笔记缺失中间阶段；任务缺失或日期与 YAML 不一致时拒绝更新；正文失败后的 YAML 回滚及回滚失败提示；同一笔记跨脚本加载的并发串行化；日记章节与复习历史表定位；日记回链失败不误报时长；数量 `0` 的显示；UTF-8 BOM 与 YAML 分隔符尾随空格；选区到剪贴板回退；重复卡查重的批量并发上限；以及内容保存后自动打开失败时不丢失已写入数据。

这些是独立 mock 测试，不代替在你自己的 Obsidian、Tasks 和 Obsidian_to_Anki 配置上做一次烟雾测试。首次使用前建议备份库或提交 Git。

## 性能说明

- 文件夹只在生成唯一路径时检查一次，减少重复的 Vault 查询。
- Anki 查重优先遍历 Anki 目录，并以最多 8 个文件为一批并发读取，避免大目录中的串行等待和无界并发。
- 阅读任务更新与复习历史写入合并为一次正文处理。
- 同一篇复盘的完成操作使用按文件粒度的串行锁；不同文件仍可独立处理，并发触发不会用旧缓存覆盖新状态。

这些优化不改变六项操作的输入、输出或统计口径。

## 常见问题

| 现象 | 检查项 |
|---|---|
| Macro 不在命令面板 | Choice 是否为 Macro、User Script 路径是否正确、闪电图标是否开启 |
| 提示路径不是文件夹 | `PATHS` 某一级被同名文件占用 |
| 日记没有会话回链 | 当日日记是否已存在；`PATHS.daily` 是否与实际目录一致；若已提示“时长已记录但回链失败”，不要再次补记会话 |
| 阅读或作文创建了，但没有时长 | Notice 是否提示关联会话失败；可稍后用“记录复习会话”补记一次 |
| 内容已创建但没有自动打开 | 从文件列表打开刚创建的笔记或卡片；内容已经保存，不要重复运行写入操作 |
| 完成复习被拒绝 | 活动文件类型、最早已配置且未完成的阶段、到期日期以及 YAML 与任务日期是否一致 |
| 提示找不到复习任务 | 恢复脚本生成的目标章节、唯一任务标签、复选框和与 YAML 一致的 `📅 YYYY-MM-DD` 后重试 |
| 提示 YAML 回滚失败 | 立即打开当前笔记，人工核对 YAML、任务复选框和日期后再继续 |
| Anki 没识别卡片 | 检查 Q/A 正则、正面/背面字段映射、AnkiConnect，并手动 Scan Vault |
| 卡片进入错误牌组 | 检查当日文件已有的 `TARGET DECK:` 行 |
| 新年份无法输入 | 年份上限当前硬编码为 2026；需同时修改输入配置和数值校验 |
| 面板看不到新数据 | Dashboard 与本脚本的目录常量是否同步 |

## 已知限制

- 真题年份上限当前为 2026。
- 阅读总题数固定为 5，适用于英语一阅读 A 单篇。
- 阶段复习只处理阅读与作文，不处理长难句的次日任务。
- Anki 仅生成 Q/A，不生成 Cloze，也不自动扫描。
- 路径和任务中文标签属于数据契约；自定义时需要同步修改相关脚本和已有笔记。
- 日期使用运行设备的本地时区。
